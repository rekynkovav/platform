## 🐛 НАЙДЕННЫЕ БАГИ И ПРОБЛЕМЫ

### **Категория 1: Критические проблемы (блокирующие)**

#### **🟥 БАГ #1: .env.example не соответствует текущему .env**
**Место:** Корень проекта  
**Описание:** `.env.example` содержит устаревшие переменные (Yandex Cloud, WebRTC), а текущий `.env` содержит другие переменные (PostgreSQL, Keycloak, Redis)
**Различия:**
- `.env.example`: YC_ACCESS_KEY_ID, ICE_SERVERS, API_BASE_URL, WS_URL, MASTER_KEY_ID
- `.env`: POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD, KEYCLOAK_ADMIN, REDIS_PASSWORD
**Влияние:** При копировании `.env.example` в `.env` получатся нерабочие настройки
**Приоритет:** 🔴 Критический
**Статус:** ❌ Не исправлен

#### **🟥 БАГ #2: init.bat использует несуществующие команды Keycloak**
**Место:** `init.bat` строка 124
**Описание:** Команда `docker exec -it platform-keycloak-1 /opt/keycloak/bin/kc.sh import` может не работать в новой версии Keycloak
**Влияние:** Инициализация Keycloak может завершиться ошибкой
**Приоритет:** 🔴 Критический
**Статус:** ❌ Не исправлен

### **Категория 2: Серьёзные проблемы (требуют внимания)**

#### **🟧 БАГ #3: Несоответствие паролей между .env и docker-compose.yml**
**Место:** `.env` и `docker-compose.yml`
**Описание:** 
- `.env`: `KEYCLOAK_ADMIN_PASSWORD=admin123`
- `docker-compose.yml`: `KEYCLOAK_ADMIN_PASSWORD: admin`
- `.env`: `REDIS_PASSWORD=redis_pass`
- `docker-compose.yml`: `${REDIS_PASSWORD:-redis_pass}` (корректно)
**Влияние:** Keycloak может не запуститься из-за неверного пароля
**Приоритет:** 🟠 Высокий
**Статус:** ❌ Не исправлен

#### **🟧 БАГ #4: backup.bat использует фиксированный пароль Redis**
**Место:** `backup.bat` строка 234
**Описание:** `redis-cli -a redis_pass` - пароль захардкожен, должен браться из `.env`
**Влияние:** Бекап Redis не будет работать если пароль другой
**Приоритет:** 🟠 Высокий
**Статус:** ❌ Не исправлен

#### **🟧 БАГ #4: init.bat предполагает существование таблицы users**
**Место:** `init.bat` строка 136
**Описание:** SQL запрос вставляет данные в таблицу `users`, но не проверяет её существование
**Влияние:** Ошибка если миграции не создали таблицу
**Приоритет:** 🟠 Высокий
**Статус:** ❌ Не исправлен
