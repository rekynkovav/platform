# ЗОЛОТОЙ СТАНДАРТ РОЛЕЙ

## ОСНОВНЫЕ РОЛИ (9 шт.)

### 1. Базовые пользователи
- `USER_0` - обычный пользователь
- `USER_1` - премиум пользователь
- `USER_2` - продвинутый пользователь

### 2. Консультанты
- `CONSULTANT_PITANIE` - консультант по питанию
- `CONSULTANT_SPORT` - консультант по спорту

### 3. Разработчики и администраторы
- `DEVELOPER` - разработчик
- `MODERATOR_ADMIN` - модератор-администратор
- `VYACHESLAV` - владелец
- `SUPER_ADMIN` - супер-администратор

## ПРАВИЛА ИСПОЛЬЗОВАНИЯ

### 1. Регистр
- Все роли в ВЕРХНЕМ РЕГИСТРЕ
- Без кавычек в коде (кроме строковых литералов)
- Пример: `USER_0`, а не `user_0`, `User_0`, `"user"`

### 2. Формат в коде
```java
// Правильно:
hasAnyRole("USER_0", "USER_1", "USER_2")
"USER_0".equals(role)
roles.contains("MODERATOR_ADMIN")

// Неправильно:
hasAnyRole("USER", "PREMIUM", "ADVANCED")
"user".equals(role)
roles.contains("moderator_admin")
```

### 3. В SecurityConfig
```java
.requestMatchers("/api/media/stream/**").hasAnyRole(
    "USER_0", "USER_1", "USER_2", 
    "MODERATOR_ADMIN", "SUPER_ADMIN", 
    "CONSULTANT_PITANIE", "CONSULTANT_SPORT", 
    "DEVELOPER", "VYACHESLAV"
)
```

### 4. В сервисах (getUserRole)
```java
private String getUserRole(Jwt jwt) {
    List<String> roles = jwt.getClaimAsStringList("realm_access.roles");
    if (roles == null) return "USER_0";
    
    if (roles.contains("SUPER_ADMIN")) return "SUPER_ADMIN";
    if (roles.contains("VYACHESLAV")) return "VYACHESLAV";
    if (roles.contains("MODERATOR_ADMIN")) return "MODERATOR_ADMIN";
    if (roles.contains("DEVELOPER")) return "DEVELOPER";
    if (roles.contains("CONSULTANT_PITANIE")) return "CONSULTANT_PITANIE";
    if (roles.contains("CONSULTANT_SPORT")) return "CONSULTANT_SPORT";
    if (roles.contains("USER_2")) return "USER_2";
    if (roles.contains("USER_1")) return "USER_1";
    if (roles.contains("USER_0")) return "USER_0";
    
    return "USER_0";
}
```

### 5. В контроллерах
```java
@PreAuthorize("hasAnyRole('MODERATOR_ADMIN', 'SUPER_ADMIN', 'VYACHESLAV')")
@PreAuthorize("hasAnyRole('SUPER_ADMIN', 'VYACHESLAV')")
```

## ЗАПРЕЩЕННЫЕ НАЗВАНИЯ

Следующие названия НЕ ДОЛЖНЫ использоваться:
- `USER` (без цифры)
- `PREMIUM`
- `ADVANCED`
- `ADMIN` (без префикса)
- `user` (строчная)
- `premium` (строчная)
- `CREATOR`
- `OWNER`
- `NUTRITION_ADMIN`
- `SPORT_ADMIN`

## ПРОВЕРКА

Перед коммитом проверять:
1. Все ли роли соответствуют золотому стандарту
2. Нет ли запрещенных названий
3. Правильный ли регистр
4. Все ли сервисы проверяют все 9 ролей
