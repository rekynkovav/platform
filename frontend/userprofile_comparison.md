# Сравнительный анализ двух UserProfile компонентов

## 📊 Основные характеристики

| Параметр | `Profile/UserProfile.js` | `UserProfile/UserProfile.js` |
|----------|--------------------------|------------------------------|
| **Размер** | 330 строк, 17.8 KB | 392 строк, 19.0 KB |
| **Импортируется в App.js** | ❌ НЕТ | ✅ ДА |
| **Импорты** | `react`, `./UserProfile.css` | `react`, `usersApi`, `./UserProfile.css` |
| **Основное назначение** | Только оплата подписки | Полный профиль пользователя + оплата |

## 🎯 Функциональность

### ✅ Общие функции (есть в обоих):
1. **Оплата подписки** с выбором периода
2. **Генерация QR-кода** для СБП
3. **Реквизиты банка** для перевода
4. **Проверка статуса платежа**
5. **Копирование в буфер обмена**

### ❌ Только в `Profile/UserProfile.js`:
- Более простая структура
- Только демо-роль из localStorage

### ✅ Только в `UserProfile/UserProfile.js`:
1. **Загрузка данных пользователя** из API (`usersApi.getCurrentUser()`)
2. **Редактирование профиля** (username, email, phone, bio)
3. **Сохранение изменений** (`usersApi.updateCurrentUser()`)
4. **Состояние редактирования** (`editing`, `saving`)
5. **Обработка ошибок** (`error` state)
6. **Управление отображением оплаты** (`showPayment`)

## 🏗️ Структура компонента

### `Profile/UserProfile.js` (простой):
```jsx
// Только оплата
{needsPayment ? (оплата) : (подписка активна)}
```

### `UserProfile/UserProfile.js` (полный):
```jsx
// 1. Заголовок профиля
// 2. Данные пользователя (с редактированием)
// 3. Кнопка редактирования/сохранения
// 4. Оплата подписки (по кнопке "Оплатить")
```

### `Profile/UserProfile.js`:
- ❌ Нет интеграции с API пользователей
- ❌ Нет обновления данных пользователя
- ✅ Простая демо-версия

### `UserProfile/UserProfile.js`:
- ✅ Полная интеграция с бэкендом
- ✅ Загрузка и обновление данных
- ✅ Обработка ошибок API
- ✅ Состояния загрузки/сохранения

## 🎨 Визуальное сравнение

### `Profile/UserProfile.js` показывает:
1. Только экран оплаты (если нужна оплата)
2. Или сообщение "Подписка активна"

### `UserProfile/UserProfile.js` показывает:
