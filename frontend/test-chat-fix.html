5. Инструкция по использованию

После исправлений чат будет работать в двух режимах:

Режим 1: API доступен
- Сообщения отправляются на сервер
- Файлы загружаются на сервер
- Данные синхронизируются между устройствами
Режим 2: API недоступен (текущий режим)
- Сообщения сохраняются в localStorage
- Файлы сохраняются как DataURL в localStorage
- Данные доступны только в текущем браузере
- Все функции чата работают локально

Важно: При восстановлении работы API система автоматически переключится на серверный режим.
