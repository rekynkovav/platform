# API Documentation

## Аутентификация
Все API запросы требуют Bearer token в заголовке `Authorization`.

## Эндпоинты

### Пользователи
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | /api/users/me | Получить текущего пользователя |
| PUT | /api/users/me | Обновить профиль |

### Чат
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | /api/chat/{roomSlug}/messages | Получить сообщения |
| POST | /api/chat/{roomSlug}/messages | Отправить сообщение |
| WS | /ws/chat | WebSocket соединение |

### Трансляции
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | /api/broadcast/active | Активные трансляции |
| POST | /api/broadcast/start | Начать трансляцию |
| POST | /api/broadcast/{id}/stop | Остановить трансляцию |

### Платежи
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | /api/payments/create | Создать платёж |
| GET | /api/payments/{id} | Статус платежа |
