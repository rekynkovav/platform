## 🔄 ОБЯЗАТЕЛЬНОЕ ОБНОВЛЕНИЕ КОНТЕКСТА

### Когда обновлять info.md
После **КАЖДОГО** из этих действий:

1. ✅ **Изменение кода**
   - Новые файлы/компоненты
   - Рефакторинг
   - Исправление багов
   - Обновление зависимостей

2. ✅ **Изменение конфигурации**
   - Порты
   - Переменные окружения
   - Docker Compose
   - Nginx конфиг

3. ✅ **Изменение архитектуры**
   - Новые модули
   - Новые API endpoints
   - Изменение структуры БД

4. ✅ **Обнаружение проблем**
   - Баги
   - Конфликты портов
   - Ошибки зависимостей

### Формат обновления
Добавляй записи в секцию `## 🔄 CHANGELOG`:

```markdown
### 2026-04-24
- **18:45** — Добавлен новый компонент VideoPlayer в frontend/src/components/
- **18:50** — Исправлен баг с аутентификацией в MediaController.java:123
- **19:00** — Обновлён порт Redis с 6379 на 6380 (конфликт)
```

### Команда для обновления
```bash
# 1. Прочитать текущий контекст
Read("D:\\Trinity\\temp_workspace\\platform\\.claude\\info.md")

# 2. Добавить новую запись в CHANGELOG
Edit(
  file_path="D:\\Trinity\\temp_workspace\\platform\\.claude\\info.md",
  old_string="### 2026-04-24\n- **18:35** — Создан файл info.md",
  new_string="### 2026-04-24\n- **18:45** — Новое изменение\n- **18:35** — Создан файл info.md"
)

# 3. Обновить "Последнее обновление" в шапке
Edit(
  file_path="D:\\Trinity\\temp_workspace\\platform\\.claude\\info.md",
  old_string="**Последнее обновление:** 2026-04-24T18:35:34Z",
  new_string="**Последнее обновление:** 2026-04-24T18:45:00Z"
)
```

## 🚨 КРАСНЫЕ ЛИНИИ (НЕ ДЕЛАТЬ НИКОГДА)

### Безопасность
1. ❌ **НЕ коммитить** `.env` файлы с секретами
2. ❌ **НЕ хардкодить** API ключи, пароли, токены
3. ❌ **НЕ отключать** Spring Security без явного запроса
4. ❌ **НЕ игнорировать** GODMODE правила из `.qwen/AGENTS.md`

### Архитектура
1. ❌ **НЕ удалять** миграции Liquibase
2. ❌ **НЕ менять** структуру БД без миграции
3. ❌ **НЕ ломать** обратную совместимость API без версионирования

### Инфраструктура
1. ❌ **НЕ менять** порты без обновления всех конфигов (docker-compose, nginx, .env)
2. ❌ **НЕ удалять** Docker volumes с данными
3. ❌ **НЕ коммитить** `node_modules/`, `target/`, `.idea/`

## 🔍 ЧАСТЫЕ ЗАДАЧИ

### Запустить фронтенд
```bash
cd /d/Trinity/temp_workspace/platform/frontend
PORT=3005 npm start
```

### Запустить backend
```bash
cd /d/Trinity/temp_workspace/platform
mvn spring-boot:run
```

### Запустить всё через Docker
```bash
cd /d/Trinity/temp_workspace/platform
docker-compose up -d
```

### Проверить логи
```bash
# Backend
tail -f backend/logs/application.log

# Frontend (если запущен в фоне)
tail -f /tmp/frontend.log

# Docker
docker-compose logs -f backend
```
