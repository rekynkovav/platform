# Правила работы мультиагентной системы OpenCode

## Режим работы
По умолчанию ВСЕ задачи проходят полный цикл: Архитекторы → Критики → Кодер → Критик-3 (Рецензент) → Аудитор.
Исключение: тривиальные задачи (однострочные исправления, опечатки) — по решению пользователя.

## Цикл выполнения

### Шаг 1: Архитекторы (Architect-1, Architect-2)
- Анализируют задачу, предлагают варианты решения.
- Фокусируются на структуре, паттернах Spring Boot и интеграции с Liquibase/PostgreSQL.
- Формируют итоговый план.
- Отвечают строго на русском языке.

### Шаг 2: Критики (Critic-1, Critic-2)
- Получают план от архитекторов.
- Ищут логические ошибки, уязвимости безопасности и проблемы производительности.
- Проверяют соответствие стандартам Java и Docker.
- Утверждают или возвращают план на доработку.
- Отвечают строго на русском языке.

### Шаг 3: Кодер (Coder)
- Реализует утверждённое архитекторами решение.
- Использует только относительные пути и Docker-команды.
- Отвечает строго на русском языке.

### Шаг 4: Критик-3 / Рецензент (Critic-3)
- Получает готовый код от Кодера.
- Проверяет соответствие исходному плану архитекторов.
- Ищет отклонения, нереализованные требования, новые уязвимости.
- **Если найдены проблемы** → возвращает задачу на Шаг 1 (Архитекторы) с описанием ошибок.
- **Если код соответствует** → передаёт на Шаг 5.
- Отвечает строго на русском языке.

### Шаг 5: Аудитор (Auditor)
- Запускает тесты Maven через терминал.
- Проверяет целостность данных и миграции БД.
- При обнаружении ошибок возвращает задачу на Шаг 4 (Рецензент) для повторной проверки после исправлений.
- Подтверждает готовность к коммиту.
- Отвечает строго на русском языке.

## Железное правило контекста
При достижии 90% заполненности контекста ОБЯЗАТЕЛЬНО сжимать историю, оставляя:
- Суть задачи и финальные решения
- Правила из AGENTS.md (роли, цикл выполнения)
- Правила из config.json (модели, промпты агентов, разрешения)
