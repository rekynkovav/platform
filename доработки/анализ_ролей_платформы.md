- Все остальные роли имеют полный доступ к интерфейсу
- Навигация адаптируется под роль пользователя

## 🛡️ Критичная логика защиты (SecureMediaService.java)

### Метод проверки скачивания оригиналов:
```java
private boolean canDownloadOriginal(String role) {
    return "SUPER_ADMIN".equals(role);
}
```

### Логика защиты медиа:
1. **Только `SUPER_ADMIN`** может скачивать расшифрованные оригиналы
2. **Все остальные роли** (включая `VYACHESLAV` и `MODERATOR_ADMIN`) не могут скачивать оригиналы
3. **Все попытки скачивания логируются** с предупреждением:
   ```java
   log.warn("SUPER_ADMIN download: user={}, role={}, file={}", userId, userRole, fileId);
   ```

## 🔧 Логика проверки ролей в сервисах

### Общий паттерн (PostService, EventService, ArchiveService, CommentService):

```java
private String getUserRole(Jwt jwt) {
    List<String> roles = jwt.getClaimAsStringList("realm_access.roles");
    if (roles == null) return "user";
    if (roles.contains("MODERATOR_ADMIN")) return "MODERATOR_ADMIN";
    if (roles.contains("SUPER_ADMIN")) return "SUPER_ADMIN";
    if (roles.contains("VYACHESLAV")) return "VYACHESLAV";
    return "user";
}

private boolean isAdmin(String role) {
    return "MODERATOR_ADMIN".equals(role) || "SUPER_ADMIN".equals(role) || "VYACHESLAV".equals(role);
}
```

## ❌ Выявленные несоответствия

### 1. **Фронтенд vs Бэкенд vs Документация:**
- **Фронтенд использует:** `USER_0`, `USER_1`, `USER_2`, `CONSULTANT_PITANIE`, `CONSULTANT_SPORT`
- **Бэке��д в SecurityConfig:** использует те же роли
- **Документация указывает:** `USER`, `PREMIUM`, `ADVANCED`, `NUTRITION_ADMIN`, `SPORT_ADMIN`

### 2. **Отсутствие ролей в коде:**
- ❌ `PREMIUM` - вместо него используется `USER_1`
- ❌ `ADVANCED` - вместо него используется `USER_2`
- ❌ `CREATOR` - вместо него используется `DEVELOPER`
- ❌ `OWNER` - вместо него используется `VYACHESLAV`
- ❌ `CONSULTANT_ADMIN` - вместо него используется `CONSULTANT_PITANIE`
- ❌ `NUTRITION_ADMIN` - вместо него используется `CONSULTANT_PITANIE`
- ❌ `SPORT_ADMIN` - вместо него используется `CONSULTANT_SPORT`

### 3. **Консультанты:**
- Фронтенд: `CONSULTANT_PITANIE`, `CONSULTANT_SPORT`
- Документация: `NUTRITION_ADMIN`, `SPORT_ADMIN`
- В коде используются фронтенд-названия
