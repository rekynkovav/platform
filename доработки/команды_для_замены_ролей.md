## 🚨 Особые случаи

### 1. Строковые литералы vs константы
- Проверить использование кавычек: `"USER_0"` vs `'USER_0'` vs `USER_0`
- Учесть регистр: `user_0` vs `USER_0`

### 2. Комментарии в коде
- Комментарии могут содержать старые названия
- Решить, нужно ли обновлять комментарии

### 3. Логические выражения
```java
// Проверить такие конструкции:
if (role.equals("USER_0")) { ... }
if ("USER_0".equals(role)) { ... }
if (role == "USER_0") { ... } // Неправильно, но может встречаться
```
