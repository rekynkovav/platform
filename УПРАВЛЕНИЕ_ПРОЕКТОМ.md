## 📁 СТРУКТУРА ПРОЕКТА - ГДЕ ЧТО ЛЕЖИТ

Представь, что проект - это большой дом:

```
🏠 platform/                    ← Это главный дом

│   │   ├── controller/         ← Дверные звонки (принимает запросы)
│   │   ├── service/           ← Кухня (готовит данные)
│   │   ├── repository/        ← Кладовка (хранит данные)
│   │   ├── model/             ← Чертежи (описывает данные)

│   └── Dockerfile             ← Инструкция по сборке
│
├── 🎨 frontend/               ← Передний двор (интерфейс)
│   ├── src/                   ← Комнаты с интерфейсом
│   │   ├── components/        ← Мебель (кнопки, формы)
│   │   ├── hooks/            ← Инструменты (удобные функции)

├── 🚀 start.bat               ← Кнопка "ВКЛЮЧИТЬ ВСЁ"
├── ⏹️ stop.bat                ← Кнопка "ВЫКЛЮЧИТЬ ВСЁ"

## 🎮 КАК ИГРАТЬ В ЭТУ "ИГРУ" - ПОШАГОВАЯ ИНСТРУКЦИЯ

### **🎯 ШАГ 1: ПОДГОТОВКА (что нужно установить)**

Перед игрой нужно установить "игровые движки":

1. **Docker Desktop** - как Minecraft Launcher
   - Скачай с сайта docker.com
   - Установи как обычную программу
   - Запусти (появится иконка в трее)

2. **Java 17+** - для backend (если нет)
3. **Node.js 18+** - для frontend (если нет)

> **Проверка:** Открой командную строку и напиши:
> ```
> docker --version
> java --version
> node --version
> ```
> Если видишь версии - всё готово!

### **🚀 ШАГ 2: ПЕРВЫЙ ЗАПУСК (как впервые запустить игру)**

**Самый простой способ - 3 клика:**

1. **Дважды кликни на `init.bat`** ← Настроит всё с нуля
2. **Дважды кликни на `start.bat`** ← Запустит всё
3. **Дважды кликни на `status.bat`** ← Проверит, что всё работает

**Что происходит:**
- `init.bat` - как установщик игры (ставит базу данных, настраивает безопасность)
- `start.bat` - как кнопка "Играть" (запускает все сервисы)
- `status.bat` - как экран загрузки (показывает, что всё готово)

### **🎪 ШАГ 3: ЧТО МОЖНО ДЕЛАТЬ (все кнопки управления)**

У тебя есть 10 "волшебных кнопок" (файлов .bat):

#### **🎮 КНОПКА 1: `start.bat` - "ВКЛЮЧИТЬ ВСЁ"**
```
Дважды кликни → Всё запустится автоматически!
```
**Что делает:**
1. Проверяет, установлен ли Docker (как проверяет, есть ли интернет)
2. Создает файл с настройками (.env) если его нет
3. Запускает все сервисы (как включает все приборы в доме)
4. Открывает отдельные окна для backend и frontend
5. Показывает, куда можно зайти

**После запуска откроются:**
- Frontend: http://localhost:3000 ← Интерфейс (как сайт)
- Backend: http://localhost:8081 ← Сервер (невидимый работник)
- Keycloak: http://localhost:8080/auth ← Вход в систему
- Prometheus: http://localhost:9090 ← Статистика
- Grafana: http://localhost:3001 ← Красивые графики

## 🔒 КАК ЗАЩИЩЕНА СИСТЕМА (безопасность)

### **🛡️ 5 УРОВНЕЙ ЗАЩИТЫ (как крепость)**

1. **🚪 Rate Limiting (ограничение запросов)**
   - Максимум 100 запросов в минуту с одного пользователя
   - Максимум 200 запросов в минуту для админов
   - **Зачем:** Чтобы злоумышленники не могли "завалить" сервер запросами

2. **🔐 Brute Force Protection (защита от перебора паролей)**
   - Максимум 5 попыток входа
   - После 5 ошибок - блокировка на 15 минут
   - **Зачем:** Чтобы нельзя было подобрать пароль перебором

3. **🌐 CORS Protection (защита от чужих сайтов)**
   - Только разрешённые сайты могут обращаться к API
   - По умолчанию: только localhost и platform.example.com
   - **Зачем:** Чтобы другие сайты не могли украсть данные

4. **🔑 JWT Authentication (безопасные токены)**
   - Вход через Keycloak (как вход через Google)
   - Токены живут 1 час, потом нужно обновить
   - **Зачем:** Чтобы не нужно было каждый раз вводить пароль

5. **📡 WebSocket Token Security (безопасный чат)**
   - Токены передаются в заголовках (невидимо)
   - Каждое соединение проверяется
   - **Зачем:** Чтобы в чат не могли подключиться посторонние

### **⚙️ КАК НАСТРОЕНО**

- **Все API начинаются с `/api/v1/`** - как версия 1.0
- **Админские API:** `/api/v1/admin/` - отдельные ограничения
- **WebSocket:** `/ws` - отдельная защита

### **📊 ПРОИЗВОДИТЕЛЬНОСТЬ (как быстро работает)**

#### **Оптимизации (как ускорили):**
1. **Multi-stage Dockerfile** - образы меньше и быстрее
2. **G1GC Garbage Collector** - умная уборка мусора в памяти
3. **Connection Pooling (HikariCP)** - переиспользование соединений
4. **Redis Caching** - быстрая память для частых данных
5. **Batch Processing** - обработка группой, а не по одному

#### **Лимиты (чтобы не сломать):**
- **📁 Загрузка файлов:** 50 файлов/день, 5GB всего
- **💬 WebSocket:** 10,000 человек в комнате, 100,000 всего
- **📨 Запросы:** 100/минуту (обычные), 200/минуту (админы)

## 🚨 ЧТО ДЕЛАТЬ ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ

### **🎯 ПРОБЛЕМА 1: Docker не запускается**

**Симптомы:**
- `start.bat` пишет "Docker не найден"
- В трее нет иконки Docker

**Решение:**
```
1. Открой Docker Desktop
2. Подожди, пока загрузится (зелёный значок)
3. Попробуй снова start.bat
```

**Проверка:** В командной строке напиши `docker --version`

### **🎯 ПРОБЛЕМА 2: Сервисы не работают**

**Симптомы:**
- `status.bat` показывает красные крестики ❌
- В браузере не открываются страницы

**Решение:**
```
1. Запусти logs.bat
2. Выбери сервис с проблемой
3. Посмотри, что пишет в логах
4. Обычно там написано, в чём проблема
```

### **🎯 ПРОБЛЕМА 3: База данных не отвечает**

**Симптомы:**
- `test.bat` показывает ошибку PostgreSQL
- Backend не запускается

**Решение:**
```
1. Запусти stop.bat
2. Запусти clean.bat (осторожно!)
3. Запусти init.bat
4. Запусти start.bat
```

### **🎯 ПРОБЛЕМА 4: Redis не отвечает**

**Симптомы:**
- `test.bat` показывает ошибку Redis
- Кэш не работает

**Решение:**
```
1. Запусти logs.bat → выбери Redis
2. Посмотри ошибки
3. Обычно помогает перезапуск: stop.bat → start.bat
```

### **🎯 ПРОБЛЕМА 5: Backend не запускается**

**Уровни логов (как важность):**
- **👶 DEBUG** - всё подряд (для разработки)
- **📝 INFO** - обычные события (что происходит)
- **⚠️ WARN** - предупреждения (что-то не так, но работает)
- **❌ ERROR** - ошибки (что-то сломалось)
- **💀 FATAL** - критическая ошибка (всё упало)

**Где смотреть логи:**
1. **Через скрипт:** `logs.bat` → выбирай сервис
2. **Вручную:** `docker-compose logs [сервис]`
3. **В реальном времени:** `docker-compose logs -f [сервис]`

### **🔧 ЧАСТЫЕ ОШИБКИ И ИХ РЕШЕНИЯ**

#### **Ошибка: "port already in use" (порт уже используется)**
```
Решение: 
1. Запусти stop.bat
2. Подожди 10 секунд
3. Запусти start.bat
```

#### **Ошибка: "connection refused" (соединение отклонено)**
```
Решение:
1. Проверь, запущен ли Docker
2. Проверь, не блокирует ли фаервол
3. Попробуй перезапустить компьютер
```

#### **Ошибка: "out of memory" (не хватает памяти)**
```
Решение:
1. Закрой лишние программы
2. Увеличь память Docker в настройках
3. Перезапусти Docker
```

#### **Ошибка: "database does not exist" (базы данных нет)**
```
Решение:
1. Запусти clean.bat
2. Запусти init.bat
3. Запусти start.bat
```
