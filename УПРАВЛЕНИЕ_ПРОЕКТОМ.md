# УПРАВЛЕНИЕ ПРОЕКТОМ PLATFORM

## 📁 СТРУКТУРА ПРОЕКТА

```
platform/
├── backend/          # Spring Boot приложение
├── frontend/         # React приложение
├── docker/           # Docker конфигурации
├── docker-compose.yml # Все сервисы
├── .env              # Переменные окружения
├── .env.example      # Пример переменных
└── скрипты управления (.bat файлы)
```

## 🚀 СКРИПТЫ УПРАВЛЕНИЯ

### Основные скрипты:
- **`start.bat`** - Запуск всех сервисов (backend через Docker)
- **`stop.bat`** - Остановка всех сервисов
- **`status.bat`** - Проверка состояния
- **`logs.bat`** - Просмотр логов всех сервисов
- **`logs-monitoring.bat`** - Просмотр логов Prometheus и Grafana

### Вспомогательные скрипты:
- **`init.bat`** - Первоначальная настройка (проверяет 2 таблицы перед миграциями)
- **`backup.bat`** - Резервное копирование (БД, Redis, конфиги) с обработкой ошибок
- **`test.bat`** - Тестирование системы
- **`build.bat`** - Сборка проекта
- **`update.bat`** - Обновление
- **`monitoring.bat`** - Запуск мониторинга
- **`clean.bat`** - Полная очистка

## ⚙️ КОНФИГУРАЦИЯ

### Файл `.env` (обязательно создать):
```
# Базовые настройки
REDIS_PASSWORD=redis_pass
DB_PASSWORD=platform_pass_2026
KEYCLOAK_ADMIN_PASSWORD=admin
POSTGRES_PASSWORD=platform_pass_2026
POSTGRES_USER=platform_user
POSTGRES_DB=platform_db

# CORS настройки (разрешённые домены через запятую)
CORS_ALLOWED_ORIGINS=https://platform.example.com,https://admin.platform.example.com,https://api.platform.example.com

# Yandex Cloud (опционально)
YC_ACCESS_KEY_ID=
YC_SECRET_ACCESS_KEY=
YC_BUCKET_NAME=platform-storage

# SSL путь (опционально, по умолчанию ./ssl)
SSL_PATH=./ssl
```

### Создание .env:
```bash
copy .env.example .env
# Отредактируй .env файл
```

## 🎯 БЫСТРЫЙ СТАРТ

### Первый запуск:
1. Установи Docker Desktop
2. Запусти `init.bat`
3. Запусти `start.bat`
4. Открой http://localhost:3000

### Ежедневное использование:
- Утром: `start.bat`
- Вечером: `stop.bat`
- Проверка: `status.bat`

## 🚨 УСТРАНЕНИЕ ПРОБЛЕМ

### Порядок действий:
1. `logs.bat` - посмотреть ошибки
2. `test.bat` - проверить систему
3. `stop.bat` → `start.bat` - перезапустить
4. Если не помогло: `clean.bat` → `init.bat` → `start.bat`

### Частые проблемы:
- **Docker не запускается**: Проверь Docker Desktop
- **Порты заняты**: `stop.bat` → подожди 10 сек → `start.bat`
- **База не отвечает**: `clean.bat` → `init.bat`
