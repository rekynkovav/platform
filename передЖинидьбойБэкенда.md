# ВРЕМЕННЫЙ ФИКС: Мок-данные для USER_0 в личном кабинете

## Описание проблемы
Личный кабинет не работает для USER_0 в демо-режиме, потому что:
1. Фронтенд работает с мок-данными
2. Бэкенд ожидает реальных пользователей в базе данных
3. Endpoint `/api/users/me` возвращает 404 для мок-пользователей

## Решение (временное)
Добавлен fallback в `UserProfile.js` для USER_0, который предоставляет мок-данные при загрузке профиля.

## Что изменено

### Файл: `frontend/src/components/UserProfile/UserProfile.js`

#### 1. В методе `loadUser()` добавлена проверка:

```javascript
const loadUser = async () => {
    try {
        setLoading(true);
        
        // === ВРЕМЕННЫЙ ФИКС ДЛЯ USER_0 ===
        const demoRole = localStorage.getItem('demoRole');
        const isUser0Demo = demoRole === 'USER_0' && 
                           (process.env.REACT_APP_DEMO_MODE === 'true' || 
                            window.location.hostname === 'localhost');
        
        if (isUser0Demo) {
            // МОК-ДАННЫЕ ДЛЯ USER_0
            const mockUser0 = {
                id: 'user-0-demo-id',
                username: 'Пользователь 0 (Демо)',
                email: 'user0@demo.platform.ru',
                phone: '+7 (999) 000-00-00',
                role: 'USER_0',
                avatarUrl: null,
                bio: 'Демонстрационный аккаунт для показа функционала личного кабинета',
                banned: false,
                banReason: null,
                lastActiveAt: new Date().toISOString(),
                createdAt: '2024-01-01T00:00:00Z',
                // Дополнительные поля для демо
                subscriptionActive: true,
                subscriptionEnd: '2024-12-31T23:59:59Z',
                paymentMethod: 'bank_transfer',
                notificationsEnabled: true
            };
            
            setUser(mockUser0);
            setFormData({
                username: mockUser0.username,
                email: mockUser0.email,
                phone: mockUser0.phone,
                bio: mockUser0.bio
            });
            setError(null);
            setLoading(false);
            return;
        }
        // === КОНЕЦ ВРЕМЕННОГО ФИКСА ===
        
        // Обычная загрузка для остальных
        const response = await usersApi.getCurrentUser();
        setUser(response.data);
        setFormData({
            username: response.data.username || '',
            email: response.data.email || '',
            phone: response.data.phone || '',
            bio: response.data.bio || ''
        });
        setError(null);
    } catch (error) {
        console.error('Ошибка загрузки профиля:', error);
        setError('Не удалось загрузить профиль');
    } finally {
        setLoading(false);
    }
};
```

#### 2. В методе `handleSave()` добавлена аналогичная проверка:

```javascript
const handleSave = async () => {
    try {
        setSaving(true);
        
        // === ВРЕМЕННЫЙ ФИКС ДЛЯ USER_0 ===
        const demoRole = localStorage.getItem('demoRole');
        const isUser0Demo = demoRole === 'USER_0' && 
                           (process.env.REACT_APP_DEMO_MODE === 'true' || 
                            window.location.hostname === 'localhost');
        
        if (isUser0Demo) {
            // Мок-сохранение для USER_0
            const updatedUser = {
                ...user,
                username: formData.username,
                email: formData.email,
                phone: formData.phone,
                bio: formData.bio
            };
            setUser(updatedUser);
            setEditing(false);
            alert('Демо-профиль USER_0 обновлен (изменения не сохраняются в БД)');
            setSaving(false);
            return;
        }
        // === КОНЕЦ ВРЕМЕННОГО ФИКСА ===
        
        // Обычное сохранение для остальных
        const response = await usersApi.updateUser(formData);
        setUser(response.data);
        setEditing(false);
    } catch (error) {
        console.error('Ошибка сохранения профиля:', error);
        alert('Ошибка сохранения профиля');
    } finally {
        setSaving(false);
    }
};
```

## Как это работает

1. **Только для USER_0** - фикс срабатывает только когда `demoRole === 'USER_0'`
2. **Только в демо-режиме** - работает на localhost или при `REACT_APP_DEMO_MODE=true`
3. **Прозрачно для пользователя** - USER_0 видит полноценный личный кабинет
4. **Не влияет на другие роли** - USER_1, USER_2, MODERATOR_ADMIN и т.д. работают как раньше
