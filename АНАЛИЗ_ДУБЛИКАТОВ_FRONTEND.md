## 🔍 ПОДРОБНЫЙ АНАЛИЗ ДУБЛИКАТОВ

### **1. App.js vs App.tsx**

#### **Сходства:**
- ✅ Одинаковые импорты (строки 1-11)
- ✅ Одинаковая структура компонента
- ✅ Одинаковая логика аутентификации
- ✅ Одинаковые хуки состояния

#### **Различия:**
- **App.tsx** имеет TypeScript типы:
  - `interface AccessDeniedPosition`
  - `useState<string[]>` для userRoles
  - `useState<AccessDeniedPosition>` для позиции
  - `useRef<NodeJS.Timeout | null>` для таймера
  - `useState<string | null>` для authError
- **App.js** использует обычный JavaScript без типов

#### **Использование в проекте:**
- **index.js** импортирует `App` без расширения → использует `App.js`
- В импортах обеих файлов: `from './keycloak'` (без расширения)

### **2. keycloak.js vs keycloak.ts**

#### **Сходства:**
- ✅ Одинаковая конфигурация Keycloak
- ✅ Одинаковые функции: `initKeycloak`, `getUsername`, `getUserRoles`, `logout`
- ✅ Одинаковая логика инициализации

#### **Различия:**
- **keycloak.ts** имеет TypeScript интерфейсы:
  - `interface KeycloakConfig`
  - `interface KeycloakInitOptions`
  - Типы для переменных: `KeycloakInstance`, `string[]`
- **keycloak.js** использует обычный JavaScript

#### **Размеры:**
- **keycloak.js:** 2308 байт
- **keycloak.ts:** 4411 байт (почти в 2 раза больше из-за типов)

### **3. Папки context vs contexts**

#### **Содержимое:**
- **`./frontend/src/context/`**: Только `AudioPlayerContext.js`
- **`./frontend/src/contexts/`**: Только подпапка `live`

#### **Использование:**
- **App.js/App.tsx** импортируют: `from './context/AudioPlayerContext'`
- Подпапка `contexts/live` не импортируется в основных файлах

## 🎯 КРИТИЧЕСКИЙ АНАЛИЗ: ЧТО ИСПОЛЬЗУЕТСЯ СЕЙЧАС

### **1. TypeScript vs JavaScript проект?**
**Факты:**
- ❌ Нет `tsconfig.json` в корне frontend
- ❌ Нет TypeScript в зависимостях `package.json`
- ❌ `index.js` импортирует `App` (без .js/.tsx) → использует `App.js`
- ✅ Есть 14 `.ts` и 6 `.tsx` файлов

**Вывод:** Проект находится в **переходном состоянии** из JavaScript в TypeScript.

### **2. Какой файл keycloak используется?**
**Факты:**
- Оба файла App импортируют `from './keycloak'` (без расширения)
- Node.js/Webpack ищет в порядке: `.js` → `.ts` → `.tsx`
- **Скорее всего используется `keycloak.js`**

### **3. Какая структура папок используется?**
**Факты:**
- `AudioPlayerContext` импортируется из `./context/`
- Папка `contexts` содержит только подпапку `live`
- **Основная структура:** `./context/` для контекстов

## ⚠️ РИСКИ ПРИ УДАЛЕНИИ ДУБЛИКАТОВ

### **🟥 ВЫСОКИЙ РИСК:**

2. **Удаление `keycloak.js`** → сломается аутентификация, если используется .js версия

### **🟡 СРЕДНИЙ РИСК:**
1. **Удаление `App.tsx`** → потеря TypeScript версии, но проект будет работать
2. **Удаление `keycloak.ts`** → потеря TypeScript типов, но функциональность сохранится

### **🟢 НИЗКИЙ РИСК:**
1. **Удаление папки `contexts`** → если `live` подпапка не используется
2. **Переименование `contexts` → `context/live`** → безопасная реорганизация
