# Changelog

Все значимые изменения в проекте.

## [1.0.0] - 2026-05-27

### Добавлено
- Веб-платформа с чатами и трансляциями
- Система платежей и подписок (1,3,6,12 месяцев)
- Ролевая модель (USER_0 до SUPER_ADMIN)
- Интеграция с Keycloak
- WebSocket для реального времени
- HLS стриминг с перемоткой
- Мониторинг: Prometheus, Grafana, ELK, Zipkin
- Docker Compose для всего стека

### Исправлено
- Все критические уязвимости безопасности
- Оптимизирована производительность БД
- Добавлены индексы и партиционирование
